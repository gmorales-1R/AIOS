## Path convention

Throughout this repo (this file, `this.md` nodes, `.this/` facets), a leading-slash path such as `/this.md` or `/.this/node_structure.md` is **repository-root-relative**, not filesystem-root-relative. Resolve it against the repo root (the directory containing this `CLAUDE.md`), e.g. `<repo-root>/this.md`, never against `/` on disk.

Read `/this.md` (i.e. `<repo-root>/this.md`) and follow its instructions before taking any action in this repository.
